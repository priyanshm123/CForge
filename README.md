# CForge

## Project Description

CForge is a lightweight version control system built from scratch in C. It is designed to track changes to files, store different versions of a project, and maintain a history of changes through commits.

The project aims to explore the fundamental concepts behind version control systems by implementing their core functionality without relying on an existing version control engine. CForge will provide a command-line interface through which users can manage and preserve different versions of their files.

The project will focus on practical C programming concepts such as file handling, data structures, hashing, memory management, and persistent data storage.

## Overview

CForge is intended to provide a simplified understanding of how version control systems manage the evolution of a codebase. It will maintain a local repository associated with a project and allow users to track files and preserve their states over time.

The system will support core version-control operations such as initializing a repository, tracking files, creating commits, viewing the history of changes, checking the current state of files, and restoring previous versions.

CForge is not intended to be a complete replacement for Git. Instead, it is an educational implementation designed to understand and demonstrate the fundamental concepts involved in building a version control system from scratch using C.
